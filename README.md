# sat-solver

A lightweight **SAT solver built from scratch in Python**, evolving from basic backtracking to a complete **CDCL (Conflict-Driven Clause Learning)** engine.

The project implements the core techniques of modern Boolean Satisfiability solvers, is benchmarked on structured DIMACS CNF planning instances (Hanoi Tower encodings), and is validated against a reference solver (MiniSat via PySAT) on random 3-SAT instances, including UNSAT ones.

---

## Key Features

* **Two-Watched Literals (2WL):** unit propagation visits only clauses watching the falsified literal, with in-place compaction of watch lists and a cached "blocker" literal to skip satisfied clauses.
* **1UIP Conflict Analysis & Non-Chronological Backjumping:** learns an asserting clause at the First Unique Implication Point and jumps back to the second-highest decision level in it.
* **VSIDS Decision Heuristic:** every variable involved in a conflict analysis is bumped, with exponential decay. Selection uses a lazy `heapq` priority queue (stale entries are discarded on pop), so each selection costs O(log n).
* **Phase Saving:** remembers the last polarity assigned to each variable.
* **Geometric Restarts:** the restart interval starts at 100 conflicts and grows by a factor of 1.5.
* **LBD-Based Clause Database Reduction:** learned clauses are ranked by Literal Block Distance (Glucose-style). Periodically the worse half is deleted, keeping clauses with LBD <= 2 and clauses currently acting as a propagation reason.
* **Trail-Based Backtracking:** undoing assignments pops only the variables above the target level, instead of rescanning the whole assignment.
* **Compact Clause Objects:** `@dataclass(slots=True)` reduces per-clause memory usage.

## Correctness

Results are checked in two ways:

* **SAT answers** are verified by `validate_solution` against the original clauses.
* **UNSAT answers** are checked by the test suite (`pytest`):
  * 300 random 3-SAT instances near the phase transition (ratio 4.26) compared with exhaustive search;
  * 40 larger random instances (60-120 variables) compared with MiniSat through PySAT (skipped if PySAT is not installed);
  * edge cases: empty clause, conflicting unit clauses, tautologies, empty formula, SATLIB `%` trailer;
  * known-answer encodings: pigeonhole (UNSAT), N-Queens (n = 2, 3 UNSAT; n >= 4 SAT), graph coloring (K4 is 3-uncolorable, 4-colorable).

```bash
pip install pytest python-sat
pytest test.py
```

## Usage

```bash
python solver.py path/to/benchmark.cnf
```

```text
Problem: 1931 variables, 14468 clauses
conflicts:  59262
Parse time: 0.0791s
Solve time: 9.3707s
SATISFIABLE
True
```

For deep search instances, PyPy3 gives the best performance:

```bash
pypy3 solver.py hanoi5.cnf
```

## Encoders

`encoders.py` generates DIMACS instances for:

* **Pigeonhole principle** (UNSAT benchmark)
* **N-Queens**
* **Graph coloring** (`k`-colorability of an arbitrary undirected graph)

```bash
python encoders.py pigeonhole 8 php8.cnf
python encoders.py nqueens 12 queens12.cnf
python solver.py php8.cnf
```

The Hanoi instances are standard external DIMACS benchmarks.
